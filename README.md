# BetssonEscuadronMCP

Proyecto para el reto de Betsson en el Malackaton (Universidad de Málaga): **Casino Lobby, lanzamiento y jugada**.

Aplicación que, ante la publicación de un juego nuevo de casino, comprueba de forma autónoma en las webs reales de Betsson que el juego aparece en el lobby, lo lanza, juega una partida y genera capturas y un veredicto.

> En desarrollo. Normas del equipo en [CLAUDE.md](CLAUDE.md); documentación del reto en [docs/hackaton](docs/hackaton).
